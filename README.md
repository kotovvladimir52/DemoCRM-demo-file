# Система управления ремонтной компанией с AI-ассистентом (Demo)

CRM-система для компании по ремонту квартир, домов и офисов с интегрированным AI-чатботом на базе RAG.

> **Дисклеймер**: Проект является учебным демонстрационным проектом (pet-project).
> Название, логотип и контент вымышлены и не связаны с реальными компаниями, брендами или организациями.
> Проект создан исключительно в образовательных целях для демонстрации технических навыков.
> Все права на торговые марки принадлежат их законным владельцам.

## Функционал

### Для клиентов:

- **AI-консультант** — умный чат-бот, который отвечает на вопросы об услугах и ценах
- **Каталог проектов** — портфолио выполненных работ с фото
- **Прайс-лист** — актуальные цены на услуги
- **Форма заявки** — быстрый заказ консультации

### Для администраторов:

- **Управление заявками** — отслеживание лидов, изменение статусов
- **Управление проектами** — добавление/редактирование портфолио
- **Управление прайсом** — CRUD-операции с ценами
- **Аналитика** — воронка продаж, конверсия, динамика заявок
- **Чат с клиентами** — история переписки с AI-ботом

## Технологии

### Backend:

- **FastAPI** (Python 3.11) — современный асинхронный веб-фреймворк
- **SQLAlchemy + AsyncPG** — асинхронная работа с PostgreSQL
- **Pgvector** — векторный поиск для AI-чата
- **Ollama** — локальная LLM (gemma3:4b) для генерации ответов
- **HTTPX** — асинхронные HTTP-запросы
- **Docker** — контейнеризация

### Frontend:

- **React 18** + **TypeScript** — типизированный UI
- **Vite** — быстрая сборка
- **Tailwind CSS** — утилитарные стили
- **React Router** — навигация
- **Axios** — HTTP-клиент

### База данных:

- **PostgreSQL 15** — основная БД
- **PgAdmin** — администрирование

### Инфраструктура:

- **Docker Compose** — оркестрация контейнеров

## RAG-подход в AI-чате

Система использует архитектуру Retrieval-Augmented Generation для точных ответов на основе прайс-листа:

- **Векторизация запроса** — запрос клиента преобразуется в эмбеддинг через модель `nomic-embed-text` (Ollama API)
- **Поиск релевантных услуг** — вектор запроса сравнивается с векторами услуг в базе через `pgvector` (косинусное расстояние), порог релевантности < 0.65
- **Формирование контекста** — найденные услуги (название, цена, категория) добавляются в системный промпт как единственный источник правды
- **Генерация ответа** — модель `gemma3:4b` генерирует ответ строго на основе предоставленного контекста, температура 0.1 (минимум фантазии)
- **Сохранение истории** — диалог сохраняется в таблице `chat_sessions` для поддержания контекста в рамках сессии

**Преимущества:**

- Бот не выдумывает цены — использует только данные из прайса
- Семантический поиск находит услуги даже при неточных формулировках
- История диалога позволяет отвечать на уточняющие вопросы

## Аналитика

Система автоматически собирает и рассчитывает ключевые метрики бизнеса:

- **Посещения сайта** — подсчёт уникальных `session_id` в таблице `visits` для оценки охвата аудитории
- **Начало квиза** — фиксация записей в `quiz_starts` для понимания вовлечённости
- **Завершение квиза** — подсчёт количества заявок в `leads` за период (конверсия в лиды)
- **Конверсия** — расчёт по формуле `(заявки / посетители) × 100%` для оценки эффективности сайта
- **Воронка продаж** — распределение заявок по статусам: `Новая` → `В работе` → `Закрыта`
- **Динамика заявок** — группировка `leads` по дате создания для выявления трендов
- **Общая выручка** — сумма поля `revenue` у закрытых заявок

**Дополнительно:**

- Фильтрация по произвольному периоду дат

## Безопасность (MVP)

- **CORS политика** — настройка `ALLOWED_ORIGINS` в `core/config.py` для защиты API от несанкционированных запросов
- **Валидация файлов** — проверка расширения при загрузке (`ALLOWED_IMAGE_EXTENSIONS`) для предотвращения загрузки вредоносных файлов
- **Изоляция контейнеров** — отдельные сети Docker и минимальные образы для ограничения поверхности атаки
- **Асинхронные транзакции** — использование `async with db.begin()` + `rollback()` при ошибках для целостности данных
- **Экранирование ввода** — SQLAlchemy ORM (параметризованные запросы) для защиты от SQL-инъекций
- **Хранение секретов** — использование переменных окружения (`.env`)

## Установка и запуск

### Требования:

- Docker Desktop
- Git
- Ollama (локально или на сервере)

### Локальный запуск:

```bash
# 1. Установите Ollama: https://ollama.ai
# 2. Загрузите модели
ollama pull gemma3:4b
ollama pull nomic-embed-text

# 3. Клонирование репозитория
git clone <repository-url>
cd democrm

# 4. Сборка и запуск сервисов
создай .env файл
создай папку uploads в папке backend
docker compose build
docker compose up -d

# 5. Проверка работоспособности
curl http://localhost/api/health

# 6. Просмотр логов
docker compose logs -f

# 7. Проверка ответов ИИ
cd backend/tests
python test_rag_metrics.py

> Ожидай вывод в терминал
> Отчёт сохранён: METRICS_PROOF.md
```
